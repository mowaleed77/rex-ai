# تطبيقات الذكاء الاصطناعي التوليدي (الدورة C03)
- القسم: الذكاء الاصطناعي والبيانات
- المستوى: متقدم
- المدة: 36 ساعة
- صيغ التدريب: أونلاين
- السعر: 7,500 جنيه مصري
- العرض الحالي: خصم المجموعات: 10% عند حجز 3 مقاعد أو أكثر
- المتطلبات: بايثون ومعرفة أساسية بتعلم الآلة
- الفئة المستهدفة: المطورون والقادة التقنيون
- المدرب: د. منى حسن (12 سنة خبرة)
- فرص العمل: مهندس ذكاء اصطناعي، مطور تطبيقات نماذج اللغة
- الاعتماد: لا يوجد اعتماد رسمي

## الوصف
بناء مساعدين ذكيين يعتمدون على الاسترجاع (RAG) وسير عمل متعدد الوكلاء باستخدام واجهات برمجة نماذج اللغة الحديثة.

## مخرجات التعلم
- تصميم الأوامر (Prompts) وأنظمة RAG
- بناء وكلاء ذكاء اصطناعي
- تقييم ومراقبة تطبيقات نماذج اللغة
- إطلاق مساعد ذكي
